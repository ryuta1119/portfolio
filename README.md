# Portfolio

金箱竜太の作品ポートフォリオ。HTML・CSSと音源を収録しています。

## GitHub Pagesで公開する

1. GitHubで `portfolio` という公開リポジトリを作成します。
2. このフォルダの中身をリポジトリ直下へアップロードします。`index.html` が直下にあり、`audio/` も含まれる状態にします。
3. Settings → Pages → Build and deploymentで、Sourceを **Deploy from a branch**、Branchを **main / (root)** に設定して保存します。
4. 公開後、Pagesの画面に表示されるURLからサイトを開きます。
